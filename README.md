

A simple expense tracking app built with Python and Flet.

## Features
- Add expenses with title, amount, category
- View list of expenses
- Save data to JSON file
- Clean UI with Flet

## How to Run
1. Install dependencies: pip install flet
2. Run: python main.py

## Project Structure
- main.py - main app code
- data/expenses.json - stored expenses
